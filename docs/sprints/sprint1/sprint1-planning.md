## Sprintplanning


## Ziele
**Projekt Setup und Infrastruktur**

_Ziel: Technische Grundlage für die Entwicklung schaffen_

- GitHub Eingerichtet und Projekt anlegen
- Teammitglieder und LV-Leiter hinzufügen
- GitHub Board, Issues und Milestones einrichten
- CI-Pipeline einrichten
- SonarCloud integrieren
- Quality Gates konfigurieren
- .mailmap im Projekt anlegen


**Entwicklungsprozess**

_Ziel: Sauberen Entwicklungsprozess sicherstellen_

- Feature-Branch-Strategie definieren und beachten
- Commit Convention einführen
- Regelmäßige Commits & Pushes durchführen
- Pull Requests für Merges verwenden
- Main-Branch schützen (protected)
- GitHub Board aktiv pflegen


**Qualitätssicherung implementieren**

_Ziel: Hohe Codequalität von Anfang an_

- CI prüft Build automatisch
- SonarCloud analysiert Codequalität
- Quality Gates werden erfüllt
- Implementierte Logik ist getestet
- Main-Branch ist jederzeit lauffähig


**Technische Basis des Spiels**

_Ziel: Erste funktionale Grundlage des Spiels erstellen_

- Netzwerkkommunikation soll grundlegend funktionieren
- Erste Kernkomponenten / Activities implementieren
- Erste Sketche für App-UI erstellen
- Grundlegende Architektur erstellen


**Vorbereitung**

Ziel: Gute Basis für Sprint 2 haben

- Alle Stories von Sprint 1 im Board dokumentieren
- Storys und Tasks für Sprint 2 vorbereiten
- Tasks/Stories Teammitgliedern zuweisen
