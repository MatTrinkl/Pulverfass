## Definition of Ready (DoR)  
Eine User Story ist bereit für die Umsetzung, wenn die folgenden Bedingungen erfüllt sind:

- Die User Story ist klar beschrieben und für alle Teammitglieder verständlich.

- Die Akzeptanzkriterien sind definiert.

- Der fachliche Nutzen der User Story ist erkennbar.

- Die Umsetzung ist technisch möglich und das Team hat ein gemeinsames Verständnis der Aufgabe.

- Der Aufwand der User Story ist grob abschätzbar.
